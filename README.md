# Machine Learning Bootcamp 🚀

This repository contains my learning notes, practical implementations, and Google Colab notebooks from a 5-Day Machine Learning Bootcamp conducted by DevTown in collaboration with the GDG/GRG community.

The bootcamp provided a strong foundation in Machine Learning concepts through interactive sessions, hands-on coding, and real-world examples using Google Colab.

---

# 📚 Topics Covered

## 📌 Day 1 – Introduction to Machine Learning

* What is Machine Learning?
* Applications of ML
* Why and where ML is used
* Types of Machine Learning

  * Supervised Learning
  * Unsupervised Learning
  * Reinforcement Learning
* Classification and Regression
* Binary & Multi-class Classification
* Python libraries used in ML

---

## 📌 Day 2 – Supervised Learning

* Linear Regression
* Logistic Regression
* Decision Trees
* Comparison between models
* Understanding when to use different models
* Practical model analysis

---

## 📌 Day 3 – Unsupervised Learning

* Clustering Techniques
* K-Means Algorithm
* Customer Segmentation
* Pattern Discovery
* Understanding hidden patterns in datasets

---

## 📌 Day 4 – Model Evaluation Metrics

* Train-Test Split
* Accuracy Metrics
* Confusion Matrix
* Overfitting vs Underfitting
* Prevention Techniques

---

## 📌 Day 5 – Final Project & Advanced Concepts

* KNN Algorithm
* Model Comparison
* Practical ML Implementation
* Hands-on coding using Google Colab
